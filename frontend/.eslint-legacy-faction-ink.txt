# Faction surfaces not yet migrated off the global ink family (issue #1819).
# This list only ever shrinks — migrating a file means deleting its line here,
# not adding one. New files may never be added to it.
#
# Seeded from what `local/no-global-ink-on-faction-surface` actually reported on
# the day it landed: 20 files, 121 violations. The count after each path is that
# day's number, kept as a rough size signal — it is not enforced, because the
# rule is switched off per FILE and a per-line count would rot on the first
# unrelated edit.
#
# HOW TO READ THE SHAPE. Thirteen of the twenty are `Default*` archetypes, and
# `default` is `na`/Unaffiliated's own identity (ADR-0030) whose ground IS the
# app's neutral paper. On those, migrating is a RENAME — `--color-text-tertiary`
# to `--label-ink`, which is unset to exactly that value — and it buys the seam
# back without changing a pixel. They are the cheap two-thirds.
#
# The seven non-`Default*` files below are where the tier is actually wrong,
# because those sheets are dressed: a faction frame that repoints `--label-ink`
# on its own root cannot reach past an inline restatement, and on the three
# always-near-black sheets (S.N.I.D.E. 2.19:1, Singularity 2.27:1, the
# Ephemerists plate 2.01:1 in light) that is the difference between a fixable
# number and an unfixable one.
#
# NOT on this list, on purpose: the `??` fallbacks. `inkColor ?? '…tertiary'`
# only applies when a skin supplied no ink, which is the legitimate neutral
# default; the rule exempts the fallback operand outright rather than
# grandfathering a line nobody could ever delete by migrating it.
