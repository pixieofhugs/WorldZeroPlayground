# landed: 61 files, 140 violations. #1609 burns it down. The three groups below

# a .tsx decision about type and spacing, and freezing an archetype's metrics in

# `text-red-600` is #dc2626 exactly, so the light render did not move; only dark
# was ever wrong. The eight length counters went to `--color-warning` rather
# than danger — approaching a limit is not an error — which also lifts them off
# the 4.40:1 the red measured on the page.

# violation (its page dot-field wrote its own `rgba(0,0,0,0.035)`); #1609's
# group-2 pass cleared that too, so it is gone from here entirely.

# STANDING AT THE END OF GROUP 2: 24 files, 72 violations. Groups 1 and 2 are

# GROUP 2 — hand-rolled lift. Neutral chrome carrying its own

# MOSTLY CLEARED by #1609: 23 violations across 14 files. The shared elevation
# token is `--color-cast-shadow` (+ `-soft` for an ambient paper lift), a
# COLOUR — geometry stays at the call site, because blur and offset are a
# component's business and only the paint was off-theme. It is deliberately not
# `--color-overlay-strong`: a scrim reads correctly on a near-black page
# unchanged while a cast shadow disappears into it, so only the cast gets a
# dark counterpart (0.25 -> 0.7, tracking --dropdown-shadow's lift). Four sites
# that had already reached for --color-overlay-strong AS a shadow moved too —
# they were the same defect laundered through a token, invisible to this rule.
# The seven modal scrims flattened to `var(--color-overlay-strong)` outright,
# per the ruling `.filter-factions__scrim` already carries in index.css: "one
# scrim for every overlay". Three non-elevation strays went with them —

# survives dark mode, and FeedCardEraAnnouncement mixes `--badge-admin-text`.

# CLEARED — the six parked for a scheduling collision are done. The four cast
# shadows took the tokens the rest of the group already had: the two warm

# GROUP 3 — faction skins and ornament marks. READ THESE BEFORE REPOINTING.
# Gap B's judgement applies to colour exactly as it does to `text-[13px]`: a
# `--faction-*` token names a TIER, and some of these literals name a ONE-OFF
# ORNAMENT instead — Snide's `rgba(182,255,46,0.055)` ghost lettering, the
# halftone dot fields, the offset flat drop shadows that are the print
# metaphor rather than elevation. Migrating those mechanically would push
# ornament colour onto a tier it was never part of, which is the coupling
# WORLD_ZERO_STYLE.md §4a forbids. #1609 must decide per site, and a site that
# stays raw stays on THIS list with the reason written down — never behind an
# inline eslint-disable, which hides the decision from the next reader.
#
# WORKED THROUGH by #1609, per site: 18 files / 66 violations -> 12 files / 27.
# Six files came off. The rule of decision was not "is this ornament" but
# "does index.css ALREADY own this colour" — because a site whose answer is a
# NEW token is a site that costs the one blocking stylesheet bytes it does not
# have (§6, #2019: ornament for a lazy archetype belongs in the .tsx, and this
# is measured). So nothing was minted. What moved, moved onto a name that was
# already declared and in most cases already read by other surfaces:
#
#   - THREE AA FAILURES, all the same pairing. White on
#     `--faction-snide-pink` measures 3.50:1 and `--faction-snide-paper` on it
#     3.10:1; `--faction-snide-on-accent` is the ink that hue's own
#     `-on-accent` line measured, at 5.38:1. The Field Desk's PRIMARY action
#     was the 3.10. Five other surfaces that fill with this pink already inked
#     it dark, so the outliers were the bug and not the rule.
#   - A token's value hardcoded, which is group 1's defect wearing a faction
#     name: `#d8d6c8` (the LIGHT value of `--faction-snide-card-muted`) in the
#     faction body, `#cfcdbf` (its DARK value) in the hero, on surfaces that
#     render in both. Plus `#e7e4d8` and `#b7b5a7`, two more rungs invented on
#     a ground that declares exactly two. All four now read the token; the
#     worst ratio afterwards is 11.79:1 on the photocopier ink.
#   - A MODULE CONSTANT, the laundering shape §4a names. `FactionSelectCard`'s
#     `const green = "#4ade80"` reached four style objects and two hover
#     handlers as an Identifier, invisible to this rule — while the S.N.I.D.E.
#     tile directly above it already read `var(--snide-*)` throughout. Every
#     value on that tile had an exact theme-invariant token waiting.
#   - ONE ORNAMENT DRAWN N WAYS. The Singularity raster has been named in
#     index.css since #723 and eight surfaces read it; `FactionCard` was a
#     ninth density hand-rolled at 0.015, and the faction hero's was WHITE on a
#     green-phosphor terminal. The Everymen poster drop shadow is one drawing

# THE 27 THAT STAY are six ornament classes, and the reason is per class rather
# than per line — this is one metaphor at a time, not a residue of stragglers:
#
#   1. THE FLAT OFFSET PRINT SHADOW (16 of the 27, and the whole reason
#      S.N.I.D.E. and the Everymen banner dominate what is left).
#      `8px 10px 0`, `6px 8px 0`, `4px 5px 0`, `2px 3px 0` — zero blur, hard
#      edge, at eight alphas from 0.2 to 0.55. It is a flyposter's register
#      offset, not elevation: nothing is lifted, so `--color-cast-shadow` would
#      be a category error, and its 0.25 -> 0.7 dark lift would swell a printed
#      mark. Collapsing the eight alphas onto ONE print token is the honest next
#      move and it is a NEW rung — deferred only because the blocking sheet is
#      ~1.0 KB from its FAIL line. That is the upgrade path; take it when the
#      sheet has room.
#   2. HALFTONE DOT FIELDS — `rgba(182,255,46,0.055)` / `0.08` acid on ink,
#      `rgba(20,17,11,0.06)` ink on the medallion. The list's own example. The
#      density IS the drawing; `--faction-snide-acid` names the tier the strip
#      and the chit rules read, and pointing grain at it couples the two.
#   3. INSET PLATE WELLS — the Coven moon plate, the Ephemerists vote plate,
#      the S.N.I.D.E. amp panel. An inset recess is not a cast: the cast token
#      names what a surface throws onto the ground BEHIND it, and all three
#      plates are dark in both cascades, so the token's dark lift would deepen
#      a well whose ground never moved (§3, #1792). #2020 left the Coven one
#      deliberately; re-decided here and the call holds.
#   4. THE PASTED-FLYER GHOSTS — a border and a fill at 0.07 / 0.035 / 0.025,
