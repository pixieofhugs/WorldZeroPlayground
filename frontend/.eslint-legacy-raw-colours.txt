# THE 27 THAT STAY were six ornament classes, and the reason is per class rather
# than per line — this is one metaphor at a time, not a residue of stragglers.
# Class 1 is now cleared, so the standing figure is 7 FILES / 8 VIOLATIONS —
# #2343 took `SnideFactionHero`, the whole of classes 4 and 7 and two thirds of
# class 2, off in one move. It is worth naming what that move WAS: not a sweep,
# but a GROUND change on the surface those alphas were drawn against. Four of
# the five were repairs (an alpha cannot follow a ground that flips) and the
# fifth was free (a color-mix of a token IS the rgba it replaces). Three of the
# six classes below were written as standing decisions and two of them were
# really standing PREMISES about a surface that has since moved.
# Classes 2-6 keep their numbers: the site comments and two PR bodies cite them,
# and renumbering a decision record to close a gap loses the trail.
#
#   1. THE FLAT OFFSET PRINT SHADOW — CLEARED. `8px 10px 0` down to `1px 2px 0`,
#      zero blur, hard edge. A flyposter's register offset, not elevation:
#      nothing is lifted, so `--color-cast-shadow` was a category error and its
#      0.25 -> 0.7 dark lift would have swelled a printed mark.
#      The room the entry above was waiting for arrived — #2073 moved ornament
#      motion into a deferred sheet, leaving 2,571 bytes to the CSS FAIL line —
#      and the rung is `--color-print-offset`, one theme-invariant black declared
#      beside the cast tokens with the reasoning at the declaration.
#      NOT the "collapse the eight alphas onto one" the entry above proposed.
#      Taken literally that is a look change at up to sixteen of seventeen sites,
#      and nobody in this batch has a browser. So: ONE name, and STRENGTH STAYS AT
#      THE CALL SITE as `color-mix(in srgb, var(--color-print-offset) 32%,
#      transparent)` — the split group 2 already made for blur and offset ("a
#      component's business"), and the one `shared.tsx`'s byline rule makes as a
#      percentage of `currentColor`. All nine strengths (0.2 / 0.22 / 0.3 / 0.32 /
#      0.35 / 0.4 / 0.45 / 0.5 / 0.55) are preserved exactly, so the change
#      repaints no pixel; `printOffsetToken.test.ts` pins them. Collapsing them
#      is still the honest next move and is now a one-line change — it is a DESIGN
#      call for someone with eyes on seventeen surfaces, not a sweep.
#      Seventeen sites, not sixteen: FOURTEEN were on the rule's report and THREE
#      were laundered past it (`SnideProfileBody`'s `filter: drop-shadow(...)`,
#      `SnideFactionBody`'s `shadow=` prop that `TaskCrown` applies as a filter,
#      and `SnideFieldDesk`'s `const CARD_SHADOW`). The class was already the
#      house pattern on ~20 OTHER surfaces that draw this mark as
#      `color-mix(in srgb, <token> N%, transparent)`; these were the holdouts.
#      Four files came off the list. Byte cost: one declaration, comments
#      stripped by the minifier.
#   2. HALFTONE DOT FIELDS — acid on ink at 0.055 / 0.08, and photocopier ink
#      on the medallion at 0.06. The list's own example, and CLEARED for
#      `SnideFactionHero` by #2343 — for two different reasons, which is the
#      part worth carrying.
#      The reasoning above was "the density IS the drawing; pointing grain at
#      `--faction-snide-acid` couples the two". That was right about the density
#      and wrong about what a hue is FOR. The acid alphas were drawn against
#      photocopier black, and #2343 moved the hero onto the wall, which FLIPS —
#      so on xerox stock acid at 5.5% is a 0.0006 luminance step and the raster
#      painted nothing at all. They read `--faction-snide-wall-text` now, which
#      reverses polarity with its own ground, at exactly the percentages they
#      always had. A raw alpha cannot follow a ground; that is the whole of it.
#      The medallion's is the other reason: its disc is the INVARIANT
#      `--faction-snide-paper`, so 6% ink was correct in both cascades and had
#      no defect to fix — but `color-mix(in srgb, <token> N%, transparent)` IS
#      that rgba to the byte, so naming the hue repaints nothing and takes the
#      last literal off the file. **An alpha that is theme-correct still owes
#      its hue a name**; only the percentage was ever the drawing.
#   3. INSET PLATE WELLS — the Coven moon plate, the Ephemerists vote plate,
#      the S.N.I.D.E. amp panel. An inset recess is not a cast: the cast token
#      names what a surface throws onto the ground BEHIND it, and all three

#      Deliberately NOT `--faction-everymen-dispatch-rule` (0.12, every 24px),
