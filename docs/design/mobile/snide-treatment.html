Nothing invented — all --faction-snide-*. Native mode: dark. Body stays Special Elite / Courier so it's still readable at a glance.

The idiom

SNIDE's signature is the ransom title on a dark, taped, halftoned card — lifted from the real SNIDETaskCard. Anatomy, then the paste-up kit.

Ransom-card anatomy

Tape → masthead (SNIDE · dispatch #) → marker scrawl → ransom title → muted brief → Anton points. Same DOM slots as any faction card; only the paste-up changes.

Paste-up kit

Every letter picks one of six cut-out styles by its code point — paper, acid, pink, ink; Anton / Bebas / Archivo / Lora, each rotated and hard-shadowed.

Masthead Bebas + acid rule · Scrawl Permanent Marker pink · Tape striped washi · Halftone 5px acid dot screen · Points Anton in acid.
