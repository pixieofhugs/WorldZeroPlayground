World Zero · Wow — the whimsy skin

Commit to Wow and the app becomes a scrapbook of little pink windows.

Same 375px layout, same markup — but Wow doesn't just recolor: it wears its real web idiom. Cards become windows (traffic-light dots, a sparkle glyph + window title, a polka-dotted board and an inner notepad), dressed with washi tape (--faction-wow-tape), scrap corners (--faction-wow-scrap-deep), ivy sprigs (--faction-wow-ivy) and stray sparkles. Caveat script (--faction-wow-card-font), rose signal (--faction-wow). Every value resolves to a --faction-wow-* token — nothing invented. Native mode: light. Thumb targets stay honest; the sparkle is on top, not in the way.

The idiom

Wow's signature is the window card — lifted from the real WowTaskCard. Anatomy, then the sticker kit.

Window-card anatomy

Title bar (dots + sparkle + name + ▭ ✕) → dotted board → notepad. Same DOM slots as every other faction card; only the frame changes.

Sticker kit

Decoration only — placed by markup so nothing clips, never over a tap target.

Tape hsla washi · Scrap corner fold · Ivy sprig · Sparkle the WowTaskCard 4-point star · Heart the rose signal. Type stays Caveat + Courier; body never below 15px.

FieldDesk — Home

Character and quests each become their own little window, taped to a dotted board. Actions keep their reachable one-hand spot.

03

Tasks

Every task is a quest window — traffic-light dots, a sparkled title bar, dotted board and a notepad holding the hand-lettered title. Detail keeps the sticky Sign-up bar, proofs and comments.

04

Praxis

Proof windows: the photo pinned to the board with tape, a sparkled window title, stars in rose. Detail has the big touch star vote; the composer keeps Write / Preview and the media grid — all still one-hand.

05

Updates

The inbox — votes, level-ups, comments, new Wow quests. Sparkle bullets for unread, warm copy, a strip of tape on each day divider.

Faction page — Wow
