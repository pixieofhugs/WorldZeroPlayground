The stamp only prints the lines it needs. Base is always shown. A line drops out entirely when the API returns a no-op value — votes = 0, multiplier = 1.0, or no metatask applied. Below, every stamp archetype in the four single-modifier states so you can see each row appear and disappear. Total = (base + metatask) × faction multiplier + votes.

Base 12 in every column · + votes = 12 + 4 = 16 · × mult = 12 × 0.80 = 9.6 · + metatask = 12 + 20 = 32. The Full formula column stacks the whole equation inside the stamp — (base + metatask) grouped first, then × 0.80, then + 4 votes, giving 29.6 — so the metatask's multiplied contribution (+16) reads in place. The remaining box-pattern factions (Ephemerists, Cozy Coven, Coven, Albescent) follow the Unaffiliated mechanism exactly.
